# 🍪 [기획서] 쿠키런: 킹덤 멀티 모드 웹 맞추기 게임

---

## 1. 프로젝트 개요

* **프로젝트명**: 쿠키런: 킹덤 퀴즈 & 맞추기 웹 게임 (Cookie Run Kingdom Quiz Web)
* **목적**: 인기 모바일 게임 《쿠키런: 킹덤》의 대사, 스킬, 초성, 그림자, 속성을 활용하여 유저들에게 몰입감 있는 맞추기 게임 경험 제공
* **타겟 사용자**: 쿠키런 킹덤 유저, 캐주얼 퀴즈 및 게임 마니아
* **핵심 계정**: `somilabs.ai@gmail.com` (Google Drive 문서 관리)
* **기술 스택**: Next.js 15 (App Router), React 19, Tailwind CSS, Framer Motion, Supabase

---

## 2. 게임 라인업 및 서비스 구조 (우선순위 순)

본 프로젝트는 **모드 3(대사 & 스킬 퀴즈)**을 메인 시그니처 게임으로 전면에 배치하고, 서브 모드들을 단계별 탭으로 구성합니다.

| 순서 | 게임 모드 | 대표 명칭 | 플레이 방식 요약 |
| :-: | :--- | :--- | :--- |
| **01** | **[메인] 모드 3** | **대사 & 스킬 퀴즈** | 대사, 스킬 설명, 성우 힌트로 쿠키 추리 (3단계 힌트 오픈) |
| **02** | **모드 5** | **쿠키 이상형 월드컵** | 32강/16강 토너먼트 대결 및 실시간 우승자 인기 차트 |
| **03** | **모드 4** | **초성 타임어택 퀴즈** | `ㅍㅇㅂㄴㄹ ㅋㅋㅋ` 10초 타임어택 제한시간 내 맞추기 |
| **04** | **모드 2** | **실루엣 그림자 퀴즈** | 흑백 외곽선/그림자 힌트로 쿠키 외형 맞추기 |
| **05** | **모드 1** | **쿠키들 (Cookidle)** | 등급, 유형, 포지션, 원소, 출시년도 힌트로 맞추는 Wordle 방식 |

## 3. 핵심 디자인 컨셉 및 UI/UX

* **컬러 파렛트**:
  * Primary: 웜 브라운 (`#5C3D2E`), 버터 옐로우 (`#FFF5E4`), 골드 (`#FFD700`)
  * Accent: 에인션트 퍼플 (`#8A2BE2`), 레전더리 블루 (`#1E90FF`)
* **디자인 요소**: 유리스모피즘(Glassmorphism) 카드, 카드 뒤집기 애니메이션, 정답 시 폭축(Confetti) 효과
* **확장성**: `GameRegistry` 구조를 도입하여 추리 게임 모드(예: BGM/음성 맞추기, 토핑 맞추기 등)를 쉽게 추가 가능한 모듈형 설계

## 4. 로드맵 및 향후 확장 계획

1. **Phase 1**: 핵심 데이터 세트 (25종 이상) 구축 및 5가지 게임 모드 메인 UI 완성
2. **Phase 2**: Supabase 연동 (글로벌 랭킹, 연속 성공 스트릭, 이상형 월드컵 실시간 투표 집계)
3. **Phase 3**: 결과 이미지 SNS 공유 기능 (카카오톡, X/트위터, 이미지 저장)
