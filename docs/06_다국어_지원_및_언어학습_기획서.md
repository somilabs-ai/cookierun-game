# 🌍 [기획서] 쿠키런: 킹덤 게임 기반 다국어 지원 & 언어 학습(English / Español / 日本語) 전략

---

## 1. 다국어 지원의 목적 & 교육적 가치

* **재미있는 게이머 중심 학습**: 단순 단어 암기 앱 대신, 좋아하는 쿠키 캐릭터의 대사, 스킬, 이름을 게임 플레이 속에서 **영어 스펠링**, **스페인어**, **일본어**로 자연스럽게 익히는 게이미피케이션(Gamification) 효과.
* **공식 글로벌 데이터 활용**: 《쿠키런: 킹덤》의 검증된 공식 글로벌 번역 자산(영어, 스페인어, 일본어 등)을 100% 활용하여 높은 몰입감 제공.

---

## 2. 핵심 다국어 플레이 방안 (3가지 선택 모드)

```
┌────────────────────────────────────────────────────────────────────────┐
│                      [ 다국어 학습 플레이 설정 ]                        │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 언어 선택: [ 🇰🇷 한국어 ] [ 🇺🇸 English ] [ 🇪🇸 Español ] [ 🇯🇵 日本語 ]  │
│ 2. 학습 모드: [ ① 일반 번역 ]  [ ② 이중 언어 힌트 ]  [ ③ 스펠링 연습 ]   │
└────────────────────────────────────────────────────────────────────────┘
```

### ① 글로벌 UI 전체 전환 모드
* UI 텍스트 및 퀴즈 힌트/대사가 선택한 언어로 완전 전환됩니다.
* 예: English 선택 시 ➡️ *"May peace be with us all..."* 대사 힌트를 보고 `Pure Vanilla Cookie` 검색.

### ② 이중 언어 힌트 모드 (Bilingual Mode)
* **1차 힌트**: 타겟 학습 언어 (예: 스페인어 *"¡Que la paz esté con todos!"*)
* **2차 힌트**: 한국어 대사 병기 노출
* 문맥을 비교하며 스페인어/영어 문장 구조와 단어를 자연스럽게 습득.

### ③ 스펠링 빈칸 힌트 모드 (Spelling Practice Mode)
* 알파벳 철자 공부를 위해 알파벳 빈칸 및 자음 힌트 제공.
* 예: `P _ _ e  V _ n i l l a  C _ o k i e` (영어) / `G a l l e t a  d e  V a i n i l l a` (스페인어)

## 3. 게임 모드별 다국어 적용 가이드

| 게임 모드 | 기존 (한국어) | 다국어 학습 전환 안 |
| :--- | :--- | :--- |
| **대사 & 스킬 퀴즈 (Mode 3)** | 한국어 대사 힌트 | 영어/스페인어 공식 대사 힌트 + 알파벳 스펠링 힌트 |
| **초성 타임어택 (Mode 4)** | `ㅍㅇㅂㄴㄹ` 초성 | **영어/스페인어 알파벳 자음(Consonant) 힌트** (`P.V.C` / `G.V.P`) |
| **실루엣 퀴즈 (Mode 2)** | 한글 쿠키 이름 입력 | 타겟 언어로 **정확한 스펠링 타이핑** 연습 |
| **쿠키 정답 카드** | 한국어 정보 노출 | **4개국어(KO, EN, ES, JA) 단어장 카드** 및 발음 가이드 |

## 4. 데이터 스키마 설계 안 (Multi-language Data Schema)

```typescript
export interface MultiLangText {
  ko: string; // 한국어
  en: string; // 영어
  es: string; // 스페인어
  ja: string; // 일본어
}

export interface CookieData {
  id: string;
  name: MultiLangText;
  quote: MultiLangText;
  skillName: MultiLangText;
  skillDescription: MultiLangText;
  rarity: CookieRarity;
  classType: CookieClass;
  position: CookiePosition;
  element: CookieElement;
  releaseYear: number;
  imageUrl: string;
}
```

## 5. 단계별 추진 로드맵

1. **1단계 (기획 및 가이드 수립)**: 다국어 데이터 스키마 및 UI/UX 학습 가이드라인 확정 (현재 단계)
2. **2단계 (영어/스페인어 시드 데이터 구축)**: 쿠키 20종 이상의 공식 English/Español 대사 및 명칭 구축
3. **3단계 (언어 스위처 및 스펠링 힌트 UI 구현)**: 상단 언어 선택 드롭다운 및 스펠링 퀴즈 인디케이터 적용
