# 📋 [기능정의서] 쿠키런: 킹덤 맞추기 게임 상세 기능 명세

## 1. 메인 모드 (모드 3): 대사 & 스킬 퀴즈 기능 정의

### 1.1 게임 흐름
1. 게임 시작 시 무작위 쿠키 선택 (동일 세션 내 중복 방지).
2. **1단계 힌트 (대사)** 노출: *"평화가 모두와 함께하길..."*
3. 유저가 정답을 맞추지 못할 경우 **[다음 힌트 보기]** 버튼 클릭:
   * **2단계 힌트 (스킬 & 속성)**: `회복형` / `후방` / `빛 속성`
   * **3단계 힌트 (초성)**: `ㅍㅇㅂㄴㄹ ㅋㅋㅋ`
4. 정답 입력 시:
   * 정답 카드 오픈 애니메이션 & 폭죽 연출
   * 점수 계산: (1단계 정답 +100점, 2단계 +70점, 3단계 +40점) * 연속 정답 배율
   * 다음 문제로 바로 이동.

## 2. 서브 모드 기능 정의

### 2.1 모드 5: 쿠키 이상형 월드컵
* **강수 선택**: 8강, 16강, 32강 선택 가능.
* **토너먼트 대결**: 2개 쿠키 카드 중 선호 쿠키 클릭 시 승자 다음 라운드 진출.
* **최종 결승 및 랭킹**: 우승 쿠키 연출 및 전체 유저 투표 결과 비율(%) 시각화.

### 2.2 모드 4: 초성 타임어택 퀴즈
* **제한시간**: 문제당 10초 타이머.
* **콤보 시스템**: 연속 정답 시 콤보 게이지 상승 및 추가 시간 보너스(+2초).
* **결과**: 제한시간 종료 후 최종 점수 및 최고 콤보 기록 저장.

### 2.3 모드 2: 실루엣 그림자 퀴즈
* **그림자 생성**: CSS `brightness(0)` 필터 기반 실루엣 연출.
* **단계별 선명도**: 정답 입력 실패 시 실루엣이 점차 원래 색상으로 복원되는 힌트 제공.

### 2.4 모드 1: 쿠키들 (Cookidle)
* **검색 자동완성**: 쿠키 이름 입력 시 드롭다운 자동완성.
* **속성 비교**:
  * 등급 / 유형 / 포지션 / 원소: 일치(초록), 불일치(빨강)
  * 출시년도: 이전 출시(⬇️), 동일(🟢), 이후 출시(⬆️)

## 3. 공통 시스템 기능

* **게임 레지스트리 (GameRegistry)**:
  * 확장 가능한 모듈형 게임 등록 시스템
  * `registerGame({ id, title, icon, component, isMain })` 형태로 신규 게임 모드 추가 가능.
* **로컬 & Supabase 하이브리드 저장**:
  * 비회원: `localStorage` 기반 최고 점수 & 연속 성공 스트릭 저장
  * 회원: Supabase DB에 리더보드 점수 자동 동기화
