# 🌿 [가이드] somilabs-dev / somilabs-ai 듀얼 배포 및 DB 연동 가이드

---

## 1. 개요 및 워크플로우 명세

본 가이드는 `somilabs-dev` (Upstream) 및 `somilabs-ai` (Origin Fork) 간의 Fork, Git Worktree, 듀얼 Vercel 배포 및 듀얼 Supabase DB 연결을 통합적으로 관리하기 위한 표준 가이드라인입니다.

```
[ Local Git Worktree (develop) ]
       │
       ├── Push & PR ──> [ somilabs-ai / develop ] ──> Vercel (somilabs-ai) [Dev DB]
       │
       └── Push & PR ──> [ somilabs-dev / develop ] ──> Vercel (somilabs-dev) [Prod DB]
```

---

## 2. 세부 명령어 실행 절차

### 1단계: Git Remote 세팅
```bash
# 1. somilabs-dev 레포지토리를 생성 후 local 원격 등록
git remote add upstream https://github.com/somilabs-dev/cookierun-game.git

# 2. somilabs-ai 포크 레포지토리 등록
git remote add origin https://github.com/somilabs-ai/cookierun-game.git
```

### 2단계: Worktree 환경 생성
```bash
# develop 브랜치를 위한 격리된 worktree 폴더 생성
git checkout -b develop
git worktree add ../cookierun-game-dev develop
```

### 3단계: Vercel & Supabase DB 개별 연동
| 환경 | GitHub 계정/조직 | Vercel 프로젝트 | Supabase DB 프로젝트 |
| :--- | :--- | :--- | :--- |
| **Dev / Staging** | `somilabs-ai` | `cookierun-game-dev` | `somilabs-ai-db` |
| **Production** | `somilabs-dev` | `cookierun-game-prod` | `somilabs-dev-db` |

---

## 3. 이 지침을 다른 AI 및 프로젝트에 참조시키는 방법

프로젝트 루트의 `.agents/rules/` 디렉토리와 `AGENTS.md` 파일에 본 규칙을 명시함으로써, Antigravity, Claude, Cursor, Gemini 등의 AI 도구가 워크스페이스를 로드하는 순간 자동으로 본 배포 지침을 인식하고 적용하도록 설정되어 있습니다.
